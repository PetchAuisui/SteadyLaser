# Steady Laser

เลเซอร์พอยเตอร์บนจอแบบ overlay สำหรับ macOS 14+ ใช้แทน software pointer ของ Norwii Presenter
รีโมตทำหน้าที่เป็นเมาส์ตามปกติ แอปนี้วาดเลเซอร์ทับตำแหน่งเคอร์เซอร์ และไม่ได้คุยกับ dongle เลย

## ติดตั้ง

```bash
./build.sh --install
```

- คำสั่งนี้ build แอป, copy ไปที่ `/Applications/Steady Laser.app`, เปิด "เปิดอัตโนมัติตอนเข้าเครื่อง" แล้วสั่งรันแอปให้เลย
- ถ้าแค่อยาก build อย่างเดียว ใช้ `./build.sh` แอปจะอยู่ที่ `build/Steady Laser.app`

## ใช้งาน

- ไอคอนจะอยู่บนแถบเมนู (◉) ใช้เปลี่ยนโหมด รูปแบบ (เลเซอร์ / สปอตไลต์) รูปแบบเลเซอร์ (จุด / เรืองแสง / ดาวหาง) สี ขนาด และความนิ่ง
- รูปแบบ **สปอตไลต์ (Spotlight)** จะหรี่จอทั้งจอ ยกเว้นวงกลมขอบนุ่มรอบตำแหน่งที่ชี้ ใช้ได้กับทุกโหมด เช่น กดค้างปุ่ม pointer เพื่อเปิดสปอตไลต์ ขนาดวงกลมเปลี่ยนตามเมนู "ขนาด" (เล็ก 90 / กลาง 135 / ใหญ่ 195 pt)
- **กดปุ่ม Pointer 2 ครั้งแบบช้า** เพื่อสลับระหว่างเลเซอร์กับสปอตไลต์: กดสั้นๆ ปล่อย รอราวครึ่งวินาทีถึงวินาทีครึ่ง แล้วกดอีกครั้ง ครั้งที่สองกดค้างต่อได้เลย จะเห็นรูปแบบใหม่ทันที
- **ห้ามดับเบิลคลิก Pointer เร็วๆ:** รีโมตใช้ดับเบิลคลิกเร็วสลับโหมดของตัวเอง และในโหมดนั้นปุ่ม Pointer จะไม่ส่งอะไรมาเลย (กดค้างแล้วเลเซอร์ไม่ขึ้น) ถ้าเกิดขึ้น ให้ดับเบิลคลิก Pointer เร็วๆ อีก 1 ครั้งเพื่อกลับมา
- ปุ่มลัด **⌃⌥L** สำหรับเปิด/ปิดเลเซอร์
- ควรปิดแอป Norwii Presenter ก่อนใช้ เพราะแอปนั้นจะย้ายเคอร์เซอร์เองและแย่งกับแอปนี้

### ตั้งปุ่ม pointer บนรีโมตให้เป็นปุ่มเลเซอร์

1. เมนู ◉ → **ตั้งปุ่มเลเซอร์…**
2. กดปุ่ม pointer ค้างไว้จนหน้าต่างปิด แอปจะจำไว้ทันที ถ้าตอนนั้นโหมดเป็น "ปิด" หรือ "เปิดตลอด" แอปจะเปลี่ยนเป็นโหมด **แสดงเมื่อกดปุ่มเลเซอร์บนรีโมต** ให้
3. กดปุ่ม pointer ค้างไว้ เลเซอร์จะขึ้นจนกว่าจะปล่อย

ปุ่มของรีโมต Norwii N95s เมื่อไม่ได้เปิดแอป Norwii (วัดจากรีโมตจริง ทั้งต่อผ่าน dongle และต่อ Bluetooth ตรง):

| ปุ่ม | สิ่งที่รีโมตส่งมา | Steady Laser |
|---|---|---|
| Pointer กดค้าง | ⌃L ตอนเริ่มกดค้าง และ ⌃A ตอนปล่อย (คีย์ลัดเลเซอร์ของ PowerPoint) | เลเซอร์ขึ้นระหว่างกดค้าง |
| Pointer ดับเบิลคลิก | สลับโหมดเลเซอร์จริง / เลเซอร์ PowerPoint ในตัวรีโมต | ไม่มีอะไรให้แอปรับ ถ้ากดค้างแล้วเลเซอร์ไม่ขึ้น ให้ดับเบิลคลิกเพื่อสลับโหมด |
| Annotate | ⌃P, กดเมาส์ซ้ายค้างตามที่กดปุ่ม, แล้ว ⌃A | ไม่ทำให้เลเซอร์ขึ้น (ยังไม่รองรับการวาด) |
| Eraser | ตัว `E` กดค้าง = ปรับเสียง | ไม่ได้ใช้ |

ข้อควรรู้:
- แอปมองเห็นเฉพาะปุ่ม Control ของ ⌃L / ⌃A โดยไม่ต้องขอสิทธิ์ Input Monitoring จึงสลับเลเซอร์ทุกครั้งที่ Control มาจากรีโมต และข้ามชุด ⌃P … ⌃A ของปุ่ม Annotate โดยดูจากการกดเมาส์ของรีโมตที่ตามมา
- แอปรับเฉพาะปุ่มจากรีโมตยี่ห้อเดียวกับที่ใช้ตอนตั้งปุ่ม (ดูจาก vendor ID) ปุ่ม Control บนคีย์บอร์ด Mac จะไม่ทำให้เลเซอร์ขึ้น และแอปอื่นยังได้รับ ⌃L / ⌃A ตามปกติ
- ปุ่มที่รับได้คือปุ่มคีย์บอร์ด, ปุ่ม modifier (⌃ ⌥ ⇧ ⌘ fn), และปุ่มเมาส์ปุ่มที่ 3 ขึ้นไป ปุ่มที่ส่งมาแวบเดียวจะกดเพื่อแสดงและกดอีกครั้งเพื่อซ่อน ส่วนปุ่มที่กดค้างได้จริงจะแสดงระหว่างกดค้าง
- ถ้ากดแล้วหน้าต่างไม่ตอบสนอง แปลว่าปุ่มนั้นไม่ได้ส่งอะไรมาที่เครื่อง เช่น ปุ่มที่ส่งเป็นปุ่มมีเดีย
- ปุ่มคีย์บอร์ดทั่วไป (ที่ไม่ใช่ modifier) จะถูกแอปนี้ใช้แทน แอปอื่นจะไม่ได้รับปุ่มนั้นอีก จึงไม่ควรเลือกปุ่มเลื่อนสไลด์

## ต่างจากแอป Norwii อย่างไร

| | Norwii Presenter 7.5 | Steady Laser |
|---|---|---|
| ตัวกรองการสั่นของมือ | ใช้อัตราขยาย 0.25–0.85 ตามความเร็ว และปัดเศษทิ้ง ทำให้ขยับช้าแล้วจุดค้าง พอเร็วขึ้นก็กระตุก | One Euro filter: นิ่งตอนขยับช้า และตามทันตอนขยับเร็ว |
| จังหวะการวาด | timer 60 Hz คลาดได้ 5 ms ไม่ sync กับจอ | display link ของแต่ละจอ (60/120 Hz) |
| แอนิเมชัน | สั่งแอนิเมชันใหม่ 0.16 วินาทีทุกเฟรม จุดเลยลอยตามหลังมือ | ไม่มีแอนิเมชันแฝง จุดวาดตรงตำแหน่งในเฟรมนั้น |
| การวาด | CPU วาดวงกลมใหม่ทุกเฟรม | ใช้ layer บน GPU |

ผล self-test (`SteadyLaser --selftest`) จำลองมือสั่น ±3 px ที่ 120 Hz:

- ระดับ "กลาง" ลดการสั่นได้ราว 93% และตอนสะบัดเร็ว 1500 px/s จุดตามหลังมือเพียงราว 8 ms

## เครื่องมือสำหรับนักพัฒนา

```bash
"build/Steady Laser.app/Contents/MacOS/SteadyLaser" --snapshot styles.png   # เรนเดอร์ทุกสไตล์เป็นรูป
"build/Steady Laser.app/Contents/MacOS/SteadyLaser" --selftest              # วัดตัวกรอง
"build/Steady Laser.app/Contents/MacOS/SteadyLaser" --snapshot-capture p.png # เรนเดอร์หน้าต่างตั้งปุ่ม
"build/Steady Laser.app/Contents/MacOS/SteadyLaser" --snapshot-spotlight s.png # เรนเดอร์สปอตไลต์ทุกขนาดบนสไลด์ตัวอย่าง
swift test                                                                    # รัน unit test
```

เปิดบันทึกการทำงาน (ปุ่มรีโมต การซ่อนเคอร์เซอร์) ไว้ไล่ปัญหา แล้วเปิดแอปใหม่ จากนั้นดูไฟล์ `~/Library/Logs/SteadyLaser.log`:

```bash
defaults write local.steadylaser debugLog -bool true
```

### Unit test และ CI

- `swift test` ทดสอบตัวกรอง One Euro (ระดับ "กลาง" ต้องลดการสั่นได้เกิน 85% และตามหลังไม่เกิน 15 ms), การบันทึกปุ่มเลเซอร์, การจับคู่รีโมตด้วย vendor ID และจังหวะกด/กดค้าง/กด 2 ครั้ง ของปุ่มเลเซอร์ ด้วยนาฬิกาจำลอง
- GitHub Actions ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)) รันทุก pull request และทุกครั้งที่ push เข้า `main` ขั้นตอนคือ build แบบ release, unit test, `--selftest`, สร้าง `.app` ด้วย `./build.sh` และเรนเดอร์ snapshot ทั้งสามแบบ
- ไฟล์ `SteadyLaser.zip` (แอปที่ sign แบบ ad-hoc) และรูป snapshot ดาวน์โหลดได้จากหน้า run ของ Actions เก็บไว้ 14 วัน

## โครงสร้างโค้ด

- `LaserController.swift` — อ่านตำแหน่งเมาส์ทุกเฟรม กรองด้วย One Euro จัดการการเฟด และหยุด display link เมื่อไม่มีอะไรขยับ
- `LaserRenderer.swift` — สร้างเลเซอร์จาก CALayer: glow, หางดาวหาง (ribbon), ตัวจุด และสปอตไลต์ (radial gradient ใหญ่พอคลุมทั้งจอ แค่ย้ายตำแหน่งทุกเฟรม ไม่วาดใหม่)
- `OverlayWindow.swift` — หน้าต่างใสคลิกทะลุได้ หนึ่งหน้าต่างต่อหนึ่งจอ แสดงอยู่เหนือสไลด์แบบเต็มจอ
- `CursorHider.swift` — ซ่อนเคอร์เซอร์ระบบ โดยใช้ private API `SetsCursorInBackground` (ถ้า API นี้ใช้ไม่ได้ เคอร์เซอร์จะแสดงตามปกติ) Dock แถบเมนู และการสลับแอปจะทำให้เคอร์เซอร์โผล่กลับมา แอปจึงซ่อนซ้ำเมื่อเคอร์เซอร์ออกจากขอบจอฝั่ง Dock หรือแถบเมนู และเมื่อสลับแอป
- `DebugLog.swift` — บันทึกการทำงานแบบเลือกเปิด (`debugLog`)
- `LaserButton.swift` — เก็บปุ่มเลเซอร์ที่ตั้งไว้ และหน้าต่างที่รอให้กดปุ่มบนรีโมตเพื่อจำปุ่ม
- `HotKey.swift` — global hotkey ผ่าน Carbon รองรับทั้งกดและปล่อย และไม่ต้องขอสิทธิ์อะไรเพิ่ม
- `AppDelegate.swift` — เมนู, ผูกปุ่มเลเซอร์, ตั้งเปิดอัตโนมัติตอนเข้าเครื่อง (`SMAppService`)
- `OneEuroFilter.swift`, `Settings.swift`
