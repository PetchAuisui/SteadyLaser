# Steady Laser

เลเซอร์พอยเตอร์บนจอแบบ overlay สำหรับ macOS 14+ ใช้แทน software pointer ของ Norwii Presenter
รีโมตทำหน้าที่เป็นเมาส์ตามปกติ แอปนี้วาดเลเซอร์ทับตำแหน่งเคอร์เซอร์ และไม่ได้คุยกับ dongle เลย

## ติดตั้ง

```bash
./build.sh --install
```

- คำสั่งนี้ build แอป, copy ไปที่ `/Applications/Steady Laser.app`, เปิด "เปิดอัตโนมัติตอนเข้าเครื่อง" แล้วสั่งรันแอปให้เลย
- ถ้าแค่อยาก build อย่างเดียว ใช้ `./build.sh` แอปจะอยู่ที่ `build/Steady Laser.app`

## ใช้งาน

- ไอคอนจะอยู่บนแถบเมนู (◉) ใช้เปลี่ยนโหมด รูปแบบ สี ขนาด และความนิ่ง
- ปุ่มลัด **⌃⌥L** สำหรับเปิด/ปิดเลเซอร์
- ควรปิดแอป Norwii Presenter ก่อนใช้ เพราะแอปนั้นจะย้ายเคอร์เซอร์เองและแย่งกับแอปนี้

### ตั้งปุ่ม pointer บนรีโมตให้เป็นปุ่มเลเซอร์

1. เมนู ◉ → **ตั้งปุ่มเลเซอร์…**
2. กดปุ่ม pointer (หรือปุ่มอื่นที่ต้องการ) บนรีโมต แอปจะจำไว้ทันที ถ้าตอนนั้นโหมดเป็น "ปิด" หรือ "เปิดตลอด" แอปจะเปลี่ยนเป็นโหมด **แสดงเมื่อกดปุ่มเลเซอร์** ให้
3. กดหนึ่งครั้ง เลเซอร์จะขึ้น กดอีกครั้ง เลเซอร์จะหาย ส่วนปุ่มที่ส่งสัญญาณตอนปล่อยด้วย (เช่น คีย์บอร์ด) ถ้ากดค้างเกิน 0.3 วินาที เลเซอร์จะหายเมื่อปล่อย

ข้อควรรู้:
- ปุ่ม pointer ของ Norwii (dongle "BLE Presenter Dongle") ส่งปุ่ม Control (⌃) แบบกดแวบเดียวประมาณ 20 ms ไม่ว่าจะกดค้างนานแค่ไหน จึงกดค้างเพื่อแสดงไม่ได้ ต้องกดเพื่อแสดงแล้วกดอีกครั้งเพื่อซ่อน
- ปุ่ม Control ที่แอปรับคือปุ่มจากอุปกรณ์ที่ใช้ตอนตั้งปุ่มเท่านั้น ปุ่ม Control บนคีย์บอร์ด Mac จะไม่ทำให้เลเซอร์ขึ้น และแอปอื่นยังได้รับปุ่มนี้ตามปกติ
- ปุ่มที่รับได้คือปุ่มคีย์บอร์ด, ปุ่ม modifier ที่กดเดี่ยวๆ (⌃ ⌥ ⇧ ⌘ fn), และปุ่มเมาส์ปุ่มที่ 3 ขึ้นไป โดยไม่ต้องขอสิทธิ์เพิ่ม
- ถ้ากดแล้วหน้าต่างไม่ตอบสนอง แปลว่าปุ่มนั้นไม่ได้ส่งอะไรมาที่เครื่อง เช่น ปุ่มที่ส่งเป็นปุ่มมีเดีย
- ปุ่มคีย์บอร์ดทั่วไป (ที่ไม่ใช่ modifier) จะถูกแอปนี้ใช้แทน แอปอื่นจะไม่ได้รับปุ่มนั้นอีก จึงไม่ควรเลือกปุ่มเลื่อนสไลด์

## ต่างจากแอป Norwii อย่างไร

| | Norwii Presenter 7.5 | Steady Laser |
|---|---|---|
| ตัวกรองการสั่นของมือ | ใช้อัตราขยาย 0.25–0.85 ตามความเร็ว และปัดเศษทิ้ง ทำให้ขยับช้าแล้วจุดค้าง พอเร็วขึ้นก็กระตุก | One Euro filter: นิ่งตอนขยับช้า และตามทันตอนขยับเร็ว |
| จังหวะการวาด | timer 60 Hz คลาดได้ 5 ms ไม่ sync กับจอ | display link ของแต่ละจอ (60/120 Hz) |
| แอนิเมชัน | สั่งแอนิเมชันใหม่ 0.16 วินาทีทุกเฟรม จุดเลยลอยตามหลังมือ | ไม่มีแอนิเมชันแฝง จุดวาดตรงตำแหน่งในเฟรมนั้น |
| การวาด | CPU วาดวงกลมใหม่ทุกเฟรม | ใช้ layer บน GPU |

ผล self-test (`SteadyLaser --selftest`) จำลองมือสั่น ±3 px ที่ 120 Hz:

- ระดับ "กลาง" ลดการสั่นได้ราว 93% และตอนสะบัดเร็ว 1500 px/s จุดตามหลังมือเพียงราว 8 ms

## เครื่องมือสำหรับนักพัฒนา

```bash
"build/Steady Laser.app/Contents/MacOS/SteadyLaser" --snapshot styles.png   # เรนเดอร์ทุกสไตล์เป็นรูป
"build/Steady Laser.app/Contents/MacOS/SteadyLaser" --selftest              # วัดตัวกรอง
"build/Steady Laser.app/Contents/MacOS/SteadyLaser" --snapshot-capture p.png # เรนเดอร์หน้าต่างตั้งปุ่ม
```

## โครงสร้างโค้ด

- `LaserController.swift` — อ่านตำแหน่งเมาส์ทุกเฟรม กรองด้วย One Euro จัดการการเฟด และหยุด display link เมื่อไม่มีอะไรขยับ
- `LaserRenderer.swift` — สร้างเลเซอร์จาก CALayer: glow, หางดาวหาง (ribbon), และตัวจุด
- `OverlayWindow.swift` — หน้าต่างใสคลิกทะลุได้ หนึ่งหน้าต่างต่อหนึ่งจอ แสดงอยู่เหนือสไลด์แบบเต็มจอ
- `CursorHider.swift` — ซ่อนเคอร์เซอร์ระบบ โดยใช้ private API `SetsCursorInBackground` (ถ้า API นี้ใช้ไม่ได้ เคอร์เซอร์จะแสดงตามปกติ)
- `LaserButton.swift` — เก็บปุ่มเลเซอร์ที่ตั้งไว้ และหน้าต่างที่รอให้กดปุ่มบนรีโมตเพื่อจำปุ่ม
- `HotKey.swift` — global hotkey ผ่าน Carbon รองรับทั้งกดและปล่อย และไม่ต้องขอสิทธิ์อะไรเพิ่ม
- `AppDelegate.swift` — เมนู, ผูกปุ่มเลเซอร์, ตั้งเปิดอัตโนมัติตอนเข้าเครื่อง (`SMAppService`)
- `OneEuroFilter.swift`, `Settings.swift`
